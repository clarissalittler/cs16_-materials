Exercises

  1. Basic: Ask for first and last name separately, then print them together in the format "Last, First".
  2. Basic: Ask for three words and print them in reverse order (if user enters "cat dog bird", print "bird dog cat").
  3. Intermediate: Create a Mad Libs program that asks for a noun, verb, adjective, and adverb, then inserts them into a story template like: "The [adjective] [noun] decided to [verb] [adverb]."
