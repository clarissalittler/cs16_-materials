The dirty truth about booleans in C++

Beware, a mildly cursed corner of C++ awaits you in this section. The key thing to understand is not that booleans are "secretly ints" in every possible sense, but that C++ allows a lot of implicit conversion between bool and integer types.

Compile this code and run it and you'll see the important fact: C++ will freely convert between bool and integers in many situations. In particular, true converts to 1 and false converts to 0 when an integer is needed, and integers convert back to bool when C++ needs a truth value.

Look at this code carefully. if(num) does not mean "if num is greater than 3". It means "convert num to a boolean and test that". Zero becomes false. Any nonzero value becomes true.

Similarly, return false; in main works because main returns an int, and false is converted to 0. So the compiler isn't ignoring the types here. It's following a conversion rule.

That flexibility is one reason experienced C++ programmers try to write conditions clearly and avoid leaning too hard on implicit conversions.

Annoying? Yes. Important to know about? Also yes.
