Menu-Driven Programs

One of the most common patterns in interactive programs is the menu: you display a list of options, ask the user to choose one, and then perform the corresponding action. This is such a common pattern that you'll use it in almost every program you write.

Basic Menu Pattern

The basic principle is pretty simple:

  • create a variable to hold a number (an int, most likely) or a variable to hold text (a char or string)
  • print out a prompt that explains the menu
  • read in the option chosen into the variable you made
  • use if-statements or switch to decide what to do next

If it doesn't fully click yet, feel free to just use the if/else version above; they do the same job.

Exercises

  1. Basic: Create a menu for a restaurant that displays 5 food items and their prices, then displays the price of whichever item the user selects.
  2. Intermediate: Create a temperature converter menu with options to convert between Fahrenheit, Celsius, and Kelvin. Include an option to exit.
  3. Challenge: Create a text-adventure game with multiple locations. Each location has a menu of places you can go next.
