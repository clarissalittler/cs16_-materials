When to Use getline() vs cin >>

  • Use cin >> when you want a single word or number
  • Use getline() when you want an entire line that might contain spaces
  • Remember to use cin.ignore() if you mix them!

Wait, what? How can -1 and 18446744073709551615 be the same thing?

Here's a hint that'll have to do for now. Imagine you have a car odometer that only goes from 0 to 999. If you're sitting at 0 and you try to roll it backwards by one, it wraps around to 999. So on that odometer, "one less than zero" and "the biggest number I can show" are the same physical reading. It turns out that the way C++ actually stores numbers is a lot like that odometer, and find uses a number type where zero and negative numbers behave this way: -1 and "the biggest possible value" end up being the same bit pattern. That's why -1 and string::npos can compare equal even though one looks tiny and negative and the other looks absurdly huge.

Character Classification Functions

When working with strings character by character, you often need to check what kind of character you're dealing with. Is it a letter? A digit? Whitespace? C++ provides a set of handy functions in the <cctype> library for this.

Here are the most useful ones:

  • isalpha(ch) - returns true if ch is a letter (a-z or A-Z)
  • isdigit(ch) - returns true if ch is a digit (0-9)
  • isspace(ch) - returns true if ch is whitespace (space, tab, newline)
  • isupper(ch) - returns true if ch is an uppercase letter
  • islower(ch) - returns true if ch is a lowercase letter
  • isalnum(ch) - returns true if ch is alphanumeric (letter or digit)

Caesar Cipher Concept

A Caesar cipher is one of the oldest encryption techniques. It works by shifting each letter in the alphabet by a fixed number of positions. For example, with a shift of 3:

  • A becomes D
  • B becomes E
  • Z wraps around to C

The interesting challenges in implementing this are:

  1. Wraparound: What happens when you shift 'Z' forward?
  2. Case preservation: Keep uppercase letters uppercase, lowercase letters lowercase
  3. Non-letters: Don't encrypt spaces, punctuation, numbers

The Wraparound Problem

When you shift a letter past 'Z' or 'z', it should wrap back to 'A' or 'a'. The modulo operator (%) is perfect for this!

Think about it: if we convert letters to numbers (A0, B1, ... Z=25), then shifting becomes addition with wraparound:

  • (position + shift) % 26 gives us the new position
  • The % 26 makes 26 wrap to 0, 27 wrap to 1, etc.

Case Preservation

You need to handle uppercase and lowercase separately:

  • For uppercase: work with the range 'A' to 'Z'
  • For lowercase: work with the range 'a' to 'z'
  • You can use isupper() and islower() to check

Converting Between Letters and Numbers

  • To convert a letter to a number: ch - 'A' (for uppercase) or ch - 'a' (for lowercase)
  • To convert a number back to a letter: number + 'A' (for uppercase) or number + 'a' (for lowercase)

Example of Shifting One Character

If you want to shift 'C' by 3:

  1. Convert to number: 'C' - 'A' = 2
  2. Add shift: 2 + 3 = 5
  3. Apply modulo for wraparound: 5 % 26 = 5
  4. Convert back: 5 + 'A' = 'F'

For a complete Caesar cipher, you'd apply this logic to each letter in a string using a loop!
