For-loops (and the shape of loops to come)

The syntax of for-loops

So far we've seen some examples of using while loops and now it's time to see the other kind of loop: the for-loop. Unlike while, which is "indefinite" iteration because it could theoretically go on forever, the for-loop is "definite" iteration because it should (unless there's a bug) only run for a pre-determined number of times.

If while can be thought of as "keep going until something changes", then for should be thought of as "do this X times".

Building a Centered Pyramid

Okay, now we're at the point where people start making the face that means "I understood the first two examples and now you have absolutely lost me."

That's normal. The centered pyramid is the moment where nested loops stop feeling like "oh, cute little star patterns" and start feeling like actual logic.

Here's the basic idea:

  • each row needs some spaces first
  • then each row needs some stars
  • the number of spaces goes down as the row number goes up
  • the number of stars goes up by 2 each row: 1, 3, 5, 7, &c.

So for a pyramid of height 5:

  • row 1 needs 4 spaces and 1 star
  • row 2 needs 3 spaces and 3 stars
  • row 3 needs 2 spaces and 5 stars

That means we can use these formulas:

  • spaces height - row=
  • stars 2 * row - 1=

This prints:

    *
   ***
  *****
 *******
*********

If you're staring at the 2 * row - 1 and thinking "why that?", the short answer is that odd numbers are exactly what you need if you want a single centered middle star on top and then equal growth out to the left and right.

And this is one of those places where you really do want to trace the program row by row on paper. For row 4=, for example:

  • spaces 5 - 4=, so you print 1 space
  • stars 2 * 4 - 1=, so you print 7 stars

That's the whole pyramid trick. It looks fancy, but it's really just two little arithmetic formulas glued to two loops.
