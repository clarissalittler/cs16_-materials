(Advanced) Arrays: the reasons for for

Here's a more advanced topic that you'll be needing not just for this class but for the rest of your classes where you're doing C++: arrays.

We're covering arrays here because they are, in a sense, the reason for using for loops. If, in the previous sections, you felt like "okay so a for is like a while, but more restricted?" that impression isn't wrong per se. while is the more general concept that lets us do all sorts of things but for is best when you're dealing with finite collections of stuff.

What we haven't shown you yet is what "a finite collection of stuff" looks like!

Before we start, another flag to plant: the kind of array we're about to introduce is going to feel a little annoying. You will have to tell it how big it is up front, you will have to remember that size yourself every time you do anything with it, and if you step one index off the end, C++ is not going to save you. That is not you doing something wrong — that really is what these arrays are. A few chapters from now, once we've seen pointers, we will come back to arrays a second time and the reveal is that the box we're about to hand you is, structurally, barely a box at all. For now, just meet the thing on its own terms.

Frequency Counting with Arrays

One powerful pattern with arrays is using the array indices to count things. This is especially useful for counting how many times each value appears in a dataset.

The key insight: use the value you're counting as the index into your counts array!

Here's an example: counting single die roll results.

This pattern extends to any situation where you need to count occurrences of discrete values!

You could extend this to:

  • Count letter frequencies in text (array of size 26)
  • Track scores in a game
  • Count how many students got each grade
  • Any other counting/histogram problem

The pattern is always the same:

  1. Create an array large enough to hold all possible values
  2. Initialize all counts to 0
  3. For each data point, increment the appropriate array element
  4. Loop through the array to display or analyze the results

Array Rotation Concept

Array rotation means shifting all elements to the right (or left) by some number of positions, with elements that "fall off" the end wrapping around to the beginning.

For example:

  • Original array: [1, 2, 3, 4, 5]
  • Rotate right by 2: [4, 5, 1, 2, 3]
  • Rotate left by 1: [2, 3, 4, 5, 1]

There are different approaches to implementing rotation:

Using a temporary array:

  1. Create a new array of the same size
  2. Calculate where each element should go in the rotated array
  3. Copy elements to their new positions
  4. Copy the temporary array back to the original

The modulo trick:

When rotating, you can use the modulo operator (% ) to handle wraparound:

  • For rotating right: newPosition (currentPosition + shift) % size=
  • For rotating left: newPosition (currentPosition - shift + size) % size=

The %size part makes positions wrap around. If you're at position 7 in an array of size 8, and you rotate right by 3, you end up at position (7 + 3) % 8 2=.

This is a classic array manipulation problem that combines loops, indexing, and modular arithmetic!

We're not asking "what should go into slot 0?" first. We're asking "where should the thing currently in slot i end up?" That change in perspective is the whole problem.

So if values[0] is 1 and we rotate right by 3, then it should land in slot 3.

If values[6] is 7, then it should land in slot (6 + 3) % 8 1=.

That's the wraparound. That's the whole game.

Exercises on Array Rotation

The worked example just above rotates an array right. Both of these exercises ask you to flip that around or simplify it.

  1. Basic: Write a program that fills an array of size 8 with eight numbers from the user, then rotates the array left by k positions (you also ask the user for k). For rotating left, the new position for the element currently at index i is (i - k + size) % size. The + size is there so the result stays non-negative even when i - k would otherwise have been negative. Print the array before and after.
  2. Intermediate: Rotate an array right by one position without using a second array. The trick is to remember the last element in a single temporary variable, then shift every other element one slot to the right starting from the back, then drop the saved value into slot 0. Test it by calling your function repeatedly to confirm that doing it size times brings the array back to its original order.
