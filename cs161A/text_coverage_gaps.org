* Text Coverage Gaps Analysis

This document is a working note for whoever next reviews =text.org=
against =graded_problems.org=. Most of the original "missing topic"
gaps that this file used to track are now /covered/ in the main
tutorial. What this file tracks instead, after the most recent pass,
is the result of an audit of the *exercise blocks* themselves: are
they sequenced properly, are their tier labels honest, and does each
graded problem have practice that comes /before/ it in the text?

** What changed in the most recent pass

The big move was an audit of every =*** Exercises= block in
=text.org=. The audit looked for three things:

1. /Forward references/ — exercises that ask for a technique the
   chapter has not yet introduced. These are the most damaging
   because students hit them with no tools and no signal that the
   tools exist a few pages later.
2. /Mis-tiered problems/ — items labeled "Basic" that are actually
   harder than the section's "Intermediate," or "Challenge" items
   that are mechanically the same as the Basic items.
3. /Bare sections/ — tutorial subsections that introduce a new
   pattern but don't include any practice for it.

Findings and fixes:

*** Forward-reference fixes

- *Arithmetic Challenge (was: compound interest)*. The compound-
  interest formula =A = P(1 + r/n)^(nt)= needs both =pow()= and a
  loop, and at this point in the text the student has neither. Loops
  arrive later (=** Your first while loop=) and =cmath= helpers
  arrive much later still (=** Distance Formulas=). Replaced with a
  single-item sales-receipt problem that uses only =cin=, basic
  arithmetic, and =setprecision(2)=. Doubles as direct prep for
  graded problem 13.

- *For-loop exercises*. The block had only Basic and Challenge, no
  Intermediate. The Basic was Fibonacci-20 (which needs three
  rolling variables and is harder than most Intermediate items). The
  Challenge was "all primes 1–100" with a sqrt hint, which both
  forward-references =cmath= and silently duplicates the
  =isPrime= worked example a few chapters later. Rewrote the block
  to: Basic = sum 1..N, Intermediate = factorial of N, Challenge =
  Fibonacci-20. All three use only the for-loop machinery just
  introduced.

- *Strings exercises (in "Simple operations on strings")*. Every
  problem in this block (count vowels, check palindrome, word
  censor) needed string iteration, character classification, or
  =find=/=substr=, all of which appear /later/ in the same chapter.
  Deleted the block from its old location and folded its three
  problems into the existing "Exercises on Character Classification"
  block, retitled to "Exercises on Strings and Character
  Classification" since both sets exercise the same machinery.

*** Tier rebalancing

- *Hello World "Advanced"*. The third item was a guided walkthrough
  ("copy this line, then this line, congratulations you wrote a
  function") rather than an exercise. Promoted to its own
  =*** Walkthrough: your first function= subsection. The Exercises
  block now contains only Basic + Intermediate, which is honest.

- *Foundations Exercises (Echoing text)*. Mad Libs was labeled
  Challenge but is structurally identical to the Basic item — just
  more =cin >>= calls in a row. Re-tiered: the previous Intermediate
  ("reverse three words") moves down to Basic, Mad Libs moves down
  to Intermediate, no Challenge. At this point in the text the
  student has zero conditional or looping tools, so a real Challenge
  isn't honestly possible.

- *Booleans Exercises*. Added an Intermediate that forces compound
  conditions: a car-rental eligibility checker that requires =&&=
  /and/ =||= in the same =if=. The previous block only had a
  Challenge that touched on compounding; nothing drilled it.

- *Pass-by-reference Exercises*. Expanded from three problems to
  five, adding a second Intermediate (=minMax= with two reference
  outputs) and a second Challenge (=splitDuration= with three
  reference outputs). These are direct shape-prep for graded
  problems 14 (search-and-replace with a count out-parameter) and
  15 (time-converter with multiple out-parameters), which the old
  three-problem block did not adequately set up.

*** Bare sections that got new exercise blocks

- *Frequency Counting with Arrays / Counting the Sums of Two Dice*.
  These two subsections introduced a load-bearing pattern (use the
  data value as an array index) but had zero practice attached.
  Added a two-item =*** Exercises on Frequency Counting= block at
  the end of "Counting the Sums of Two Dice": Basic = bin test
  scores into letter-grade counts, Intermediate = count three-dice
  sum frequencies. These two together are the technique behind
  graded problem 6 (dice statistics).

- *Array Rotation Concept*. Same problem: a worked example with no
  practice. Added a two-item block that asks the student to do the
  /opposite/ of the worked example: Basic = rotate left, Intermediate
  = rotate right by one position in place (no temporary array). This
  is the technique behind graded problem 10 (array rotation), and
  asking for the inverse direction prevents the exercise from being
  a copy-paste of the example.

** Practice → graded-problem coverage

After the pass, every graded problem has at least one practice
exercise that appears /earlier/ in =text.org= and uses the same
technique:

| # | Graded problem            | Practice in text.org                                                            |
|---+---------------------------+---------------------------------------------------------------------------------|
| 1 | Temperature converter      | Menu Exercises (Intermediate item is literally a temperature-converter menu)    |
| 2 | Number guessing with hints | Randomized Exercises + the =abs()= proximity section in the worked text        |
| 3 | Input validation loop      | Data Validation Exercises                                                       |
| 4 | Centered pyramid           | Worked example "Building a Centered Pyramid" + Nested Loops Exercises          |
| 5 | Grade book average         | Arrays Exercises (Basic) + Averaging-Numbers Exercises                          |
| 6 | Dice roll statistics       | Frequency Counting Exercises (new — Intermediate is dice-sum frequencies)      |
| 7 | Word statistics            | Strings & Character Classification Exercises (new merged block, Basics 1+2)    |
| 8 | Caesar cipher              | "A Complete Caesar Cipher Program" worked example                              |
| 9 | Day of week (switch)       | Switches Exercises (Basic is days-of-week)                                     |
| 10 | Array rotation            | Array Rotation Exercises (new — both items are rotation in different forms)    |
| 11 | Prime checker function    | "Example: Prime Number Checker" + Bool Functions Exercises                     |
| 12 | Distance functions        | Mathematical Functions Exercises + worked Distance Formulas                    |
| 13 | Sales receipt             | Arithmetic Exercises Challenge (new — single-item receipt)                     |

The two new entries at problems 13 and 15 are the most important
additions, because before this pass those graded problems had no
matching practice anywhere in the text.

** Open items for the next reviewer

These aren't blocking, but they are worth thinking about:

- The =** Exercises= heading at the top level under Foundations
  (around the "Echoing text and string types" section) and the
  =** Exercises= heading after "Your first while loop" are both at
  chapter level, when they should arguably be subsections of the
  preceding =**= heading. This is a structural quibble, not a
  content gap, and would change how the headings render in the
  generated website. Left alone in this pass.

- The "Discussion" item in the Scope and Lifetime exercise block
  (Item 6, "Why is it generally better to pass data to functions
  via parameters rather than using global variables?") is a writing
  prompt rather than a coding exercise. That's fine, but no other
  exercise block in the text uses a "Discussion" tier, so it sits a
  little oddly. Either commit to discussion items as a recurring
  shape or convert this one to code.

- Several lab projects in Extended Topics (Vectors, Structs, File
  I/O) are essentially the graded problems re-skinned for CS161B.
  They're fine, but if CS161B borrows them verbatim there will be
  duplication; worth a coordination check next time the two course
  outlines are reviewed together.
